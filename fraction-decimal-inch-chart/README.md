# Fraction to decimal chart for inches, with millimeters and feet

To turn a fraction of an inch into a decimal, divide the top number by the bottom one: 5/8" is 5 ÷ 8 = 0.625". The chart below does it for every 64th from 1/64" to 1", with millimeters (1 inch is exactly 25.4 mm) and decimal feet beside each one.

Printable PDF (US Letter, one page): [fraction-decimal-inch-chart.pdf](./fraction-decimal-inch-chart.pdf)
