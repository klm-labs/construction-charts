# Construction charts

Seven construction reference charts as data: CSV files, Markdown tables and the printable one-page PDFs. Fraction to decimal inches, roof pitch, board feet, concrete bags per yard, crown molding angles, stair rise and run, and square feet from feet and inches.

This is the free data behind the chart pages on [klmlabs.app](https://klmlabs.app/construction-calculator/guides/). It is made by KLM Labs, a small studio that makes [Construction Calculator](https://klmlabs.app/construction-calculator/), an iPhone and iPad calculator for feet, inches and fractions. The numbers were not typed in: the CSV and Markdown files were generated by running the site's own chart code, which uses the app's formulas (Construction Calculator 1.1.1), and every cell was checked against the live pages.

## Charts

Each folder has a README with what the chart is, how each number is worked out in plain words, the tables, and the sources and building-code sections the web page cites.

## Files

- `<chart>/<table>.csv`: one CSV per table, UTF-8, first row is the header. Cells are the text the page shows, e.g. `2' 6"` and `≈ 7-3/16"`. `≈` means the value was rounded to the nearest 1/16" (or the precision the table names).
- `<chart>/README.md`: the same tables in Markdown, with the formulas and citations.
- `<chart>/<chart>.pdf`: the printable chart, US Letter, the same file served on klmlabs.app.

## Things to know

- A printed chart is a guide: measure on site.
- The stair and roof chart notes cite the model code (the 2021 IRC, with notes on the 2024 edition). Cities, counties and states adopt a code edition, often with amendments, and the building official has the final say. This is not legal advice: check your local code before you build.
- Lumber in the board feet chart is counted on its nominal size (a 2x4 as 2" × 4"), as board feet are sold.
